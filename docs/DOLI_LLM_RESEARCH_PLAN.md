# D.O.L.I (LLM) 技术调研计划

**创建日期**: 2026-06-24  
**状态**: 计划中

---

## 调研目标

评估 D.O.L.I (LLM) 模组的技术可行性，确定集成到 DOL-X 的最佳方案。

---

## 必须回答的问题

### 1. 技术架构

- 使用什么 LLM API？（OpenAI/Anthropic/本地模型）
- 是否支持离线运行？
- 网络连接是必需还是可选？

### 2. 依赖清单

- 需要什么 Python/Node.js 依赖？
- 是否需要额外的系统依赖？
- ModLoader 版本要求？

### 3. 配置方案

- 如何配置 API key？
- 支持哪些 LLM 提供商？
- 是否支持本地模型（ollama/llama.cpp）？

### 4. 性能开销

- 响应时间？
- 内存占用？
- 对游戏性能的影响？

### 5. 集成复杂度

- 配置文档是否完整？
- 是否可作为可选 feature？
- 对构建流程的影响？

---

## 调研方法

### 阶段 1: 仓库分析（1 小时）

1. 克隆仓库: `gh repo clone ArsNativa/DOLI`
2. 阅读 README.md
3. 检查 package.json / requirements.txt
4. 分析源码中的 API 调用

### 阶段 2: 配置研究（30 分钟）

1. 查找配置文件示例
2. 分析配置选项
3. 评估配置复杂度

### 阶段 3: 可行性评估（30 分钟）

1. 本地 LLM 支持？
2. 离线运行可行性？
3. 与 DOL-X 架构兼容性？
