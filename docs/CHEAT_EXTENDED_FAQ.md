# Cheat Extended 常见问题解答

本文档解答 Cheat Extended v1.17+ 的常见使用问题。

---

## UI 使用相关

### Q: 点击侧边栏的"作弊扩展"按钮没有弹出设置界面？

**A**: 这是 **v1.17+ 版本的正常设计**，不是 bug。

从 v1.17 开始，Cheat Extended 进行了 UI 重构，从集中式面板改为**分散式原生集成**设计。

**v1.17 官方更新说明**：
> 嘗試重新設計側邊欄相關按鈕顯示方式，避免相關UI太過佔空間

**设计理念**：
- **原生集成** - 功能融入游戏原生 UI，而非独立外挂面板
- **情境触发** - 功能在需要的场景自动显示
- **快捷优先** - 高频操作放在侧边栏一键触发

---

### Q: 那我应该在哪里找到作弊扩展的功能？

**A**: Cheat Extended 的功能分布在**三个主要入口**：

#### 1️⃣ 侧边栏（快捷功能）

**功能**：
- ✅ 一键状态恢复 + PC 立即高潮
- ✅ 言靈实时显示（三代言靈系统）
- ✅ 空间节点传送（孤儿院卧室、伊甸家、随身衣柜）

**使用方式**：
- 直接点击侧边栏对应按钮**触发功能**（不是打开设置面板）
- 例如：点击"状态恢复"按钮会立即恢复角色状态

---

#### 2️⃣ 游戏选项菜单（主要设置入口）

**功能**：
- ⚙️ 属性控制面板
- ⚔️ 战斗设置（伤害加倍/疼痛衰减）
- ⏰ 时间控制
- 💰 商业功能配置
- 🥛 大量挤奶模式
- 🐍 大爆精模式
- 🎓 学习内捲模式
- 👗 添加服装功能

**使用方式**：
1. 游戏内点击 **"选项"（Options）** 按钮
2. 在选项菜单中找到 **"作弊拓展"** 相关设置
3. 调整所需功能参数

---

#### 3️⃣ 场景内 Widget（情境功能）

**功能**：
- 🏠 孤儿院卧室 → 随身衣柜（异次元空间衣柜）
- ⚔️ 战斗场景 → 敌人 HP/AP 实时显示
- ✨ 言靈编辑界面（新增/编辑/删除言靈）
- 🎨 魔术迴路功能（自定义纹身）
- 🌍 场景创建功能

**使用方式**：
- 进入对应场景后，功能会**自动显示**在页面相应位置
- 例如：进入孤儿院卧室后，会看到"随身衣柜"选项

---

### Q: 为什么要改成这种设计？旧版不是挺好的吗？

**A**: v1.17 重构的主要原因：

1. **减少 UI 占用空间**
   - 旧版独立面板占用大量屏幕空间
   - 新版分散式设计更简洁

2. **更贴近原生游戏体验**
   - 功能融入游戏原有界面
   - 不像传统"外挂面板"那样突兀

3. **按使用频率优化**
   - 高频操作（状态恢复、言靈）放侧边栏一键触发
   - 低频设置（属性调整）放选项菜单

4. **情境相关性**
   - 战斗功能在战斗时显示
   - 衣柜功能在卧室显示
   - 避免功能堆砌

## 功能使用相关

### Q: 言靈系统怎么用？

**A**: 言靈系统（三代言靈）使用方式：

**查看言靈**：
- 侧边栏会实时显示已添加的言靈列表

**新增言靈**：
1. 方式一：通过魔术迴路功能（文字框输入言靈命令）
2. 方式二：在言靈编辑界面添加

**执行言靈**：
- 点击侧边栏显示的言靈名称即可执行

**编辑/删除言靈**：
- 进入言靈编辑界面进行管理

**特点**：
- 支持同时添加多个言靈
- 调用游戏内原生 widget 和 JS
- 可自定义复杂功能序列

---

### Q: 随身衣柜在哪里？

**A**: 随身衣柜功能位置：

1. **通过空间节点传送**：
   - 侧边栏点击"空间节点"按钮
   - 选择"随身衣柜"传送

2. **在孤儿院卧室访问**：
   - 进入孤儿院卧室
   - 页面会显示"随身衣柜"选项
   - 点击进入异次元空间衣柜

**功能**：
- 存储/切换服装
- 不受场景限制的衣柜访问

---

### Q: 如何修改角色属性/时间？

**A**: 属性和时间控制位置：

1. 游戏内点击 **"选项"（Options）**
2. 找到 **"作弊拓展"** 或相关设置项
3. 在以下功能中调整：
   - **属性控制面板** - 修改角色各项属性
   - **时间控制** - 调整游戏时间
   - **Debug 模式** - 开启调试功能

**注意**：不要在侧边栏找这些功能，侧边栏只有快捷操作。

---

### Q: 战斗中的敌人 HP/AP 显示在哪里？

**A**: 战斗信息自动显示：

1. **触发条件**：进入战斗场景
2. **显示位置**：战斗界面会自动显示敌方 HP（生命值）和 AP（行动点）
3. **无需手动开启**：这是情境触发功能，战斗时自动生效

**相关设置**：
- 伤害加倍
- 疼痛衰减
- 这些功能在"选项"菜单中配置

## 版本兼容相关

### Q: 我之前用的是 v1.16，升级到 v1.17 后找不到功能了？

**A**: v1.17 是**重大 UI 重构版本**，功能位置发生变化：

**旧版（v1.16-）**：
- 点击按钮 → 打开作弊面板 → 所有功能集中在面板

**新版（v1.17+）**：
- 侧边栏 → 快捷功能触发
- 选项菜单 → 详细设置
- 场景内 → 自动显示相关功能

**建议**：
1. 重新学习新版 UI 布局（参考本 FAQ）
2. 如实在不习惯，可考虑回退到 v1.16（但会失去新功能）

---

### Q: DOL-X 现在用的是哪个版本？高版本作弊拓展需要什么？

**A**: DOL-X 当前 `vega` 和稳定 Release `v0.5.10.12-1.0.8a-0804` 都使用
**Cheat Extended v1.20 betaTest + maplebirch 框架 v4.1.13**。0713 是保留的历史 3.x 回滚版本。
上游已有 maplebirch 4.1.14，但它恢复 NPC 怀孕扩展等运行时行为，本轮继续锁定已验证的 4.1.13，
等待另案评估而不在发版前混入。

先分清两个**互相独立**的版本维度，这是历史文档最容易搞混的地方：

| 维度 | 含义 | 当前值 |
|------|------|--------|
| **框架 mod 版本** | 秋枫白桦框架（maplebirch）这个**前置 mod** 自身的版本 | v4.1.13 |
| **游戏本体版本** | Degrees of Lewdity 游戏本身的版本 | 0.5.10.12 |

当前文件名是 `maplebirch-0.5.10.12-v4.1.13.mod.zip`：前面的 `0.5.10.12` 是目标游戏版本，后面的 `v4.1.13` 才是框架 mod 自身版本。作弊拓展比较的是后者。

**v1.19/v1.20 的框架要求 = 框架 mod ≥ v3.2.5**（不是游戏版本）。

**历史勘误**：框架 v3.2.5 确实发布过，只是作者后来撤包删除了 tag；DOL-X 也确实从提交 `33129fe7` 重建过。游戏里显示的“最后更新 2026.07.27”只是重建 ZIP 的成员时间戳，不是作者发布时间。

此前曾根据依赖范围写出“v3.2.5 是唯一解”，这个结论已经被真机证据推翻。旧 maplebirchEx v1.2.4 虽然声明 `maplebirch ^3.1.0`，在 3.2.5 上却会因 `dread`、`sanity`、`dreadmax` 未初始化而报错。作者已把现役功能拆成 LongerCombat v1.0.1 和 YanlingCheatCollection v1.0.1，两者要求 maplebirch `^4.1.0`。因此当前方案是官方 4.1.13，而不是继续修补 3.x。

用户真机验证当前基础栈为 `0 error / 0 warning / 340 info`，Cheat Extended 界面可以打开，抽样的一两个功能正常。这个证据证明当前 UI 和抽样功能可用，不代表全部功能已经逐项覆盖。

详见：`config/build.toml` 中 maplebirch / cheat_extended 配置块注释

## 故障排查

### Q: 进游戏弹窗提示「maplebirch框架版本過低」，而且作弊功能完全没有？

**A**: 这是**框架 mod 版本不满足运行时门控**的典型表现，两个症状总是一起出现：弹窗 + 功能不加载。

**机制说明**（v1.19/v1.20 适用）：

作弊拓展的框架版本要求**不写在 `boot.json` 的依赖表里**。它的 `boot.json` 只声明 ModLoader、TweeReplacer、ReplacePatcher、ImageLoaderHook、SweetAlert2Mod 和游戏版本下限，**完全没有 maplebirch 这一项**。真正的检查在两个 `scriptEarly` 脚本里，在游戏运行时执行：

| 文件 | 作用 |
|------|------|
| `scriptEarly/framework_detector.js` | 若框架 mod 版本 < 3.2.5，弹出 SweetAlert2 警告窗 |
| `scriptEarly/CERegist.js` | `ModLoaderLoadEnd` 时比对版本，**不达标就只写一条 error 日志，7 个 `addTo()` 注册全部跳过** |

那 7 个注册调用（`Cheats`、`MenuBig`、`CaptionAfterDescription`、`Options`、`HintMobile`、`Footer` 等挂载点）是作弊拓展把自己接进游戏 UI 的唯一途径。跳过 = mod 虽然「加载」了，但没有任何功能入口。

所以「点掉弹窗就能正常玩」是**误解**：弹窗只是通知，真正的后果是功能一个都没注册上。

**解决办法**：把框架 mod 升到 **v3.2.5 或更高**（注意是框架 mod 版本，不是游戏版本）。DOL-X 当前 `vega` 公开主线直接使用作者官方 v4.1.13。

**验证方法**：按 `F12` 打开控制台，搜索 `[Cheat Extended]`：
- 当前放行时应看到 maplebirch 框架 v4.1.13；任何大于等于 v3.2.5 的版本都会通过这个门控
- 拦截时会看到 `maplebirch 版本過低，至少需要 v3.2.5，當前 vX.X.X`

### Q: 侧边栏的作弊扩展按钮完全不显示？

**A**: 检查项：

1. **Mod 加载验证**：
   - 按 `Alt+M` 打开 ModLoader GUI
   - 确认 `cheat extended` 出现在 Mod 列表
   - 检查状态为 `[Local]` 且无错误标记

2. **版本兼容性**：
   - 确认游戏版本为 v0.5.10.12（DOL-X 当前版本）
   - 确认 maplebirch 框架已加载，且框架 mod 版本 ≥ v3.2.5（见上一条问答）

3. **控制台检查**：
   - 按 `F12` 打开浏览器控制台
   - 查找 `[Cheat Extended]` 相关错误信息

4. **重新加载**：
   - 刷新页面（F5）
   - 清除浏览器缓存后重试

---

### Q: “头部遮罩相容模式”是谁提供的？需要再装 Legacy-Art-Mods-Compat 吗？

**A**: 当前界面里的头部遮罩相容模式由 **Cheat Extended v1.20** 提供。官方包内存在 `scripts/CE_HeadMaskCompat.js`，相关选项也由 Cheat Extended 的侧栏脚本注册。

`Legacy-Art-Mods-Compat.zip` 是另一套通用旧/新图片命名转换器，不是该选项的来源，也不是框架 4.x 的前置。DOL-X 4.x 主线已集成社区 plus 作为图片路径兼容层，但它与 Cheat Extended 的头部遮罩选项职责不同，不应重复安装或混为一谈。

---

### Q: 点击侧边栏按钮没有任何反应？

**A**: 可能原因：

1. **按钮类型误判**：
   - 确认点击的是"快捷功能"按钮（状态恢复、言靈、传送）
   - 这些按钮会**立即执行功能**而非打开界面

2. **功能条件未满足**：
   - 某些功能可能需要特定条件（如在特定场景）
   - 检查游戏内提示信息

3. **冲突检测**：
   - 检查是否与其他 mod 的 UI 冲突
   - 尝试禁用其他 mod 测试

4. **JavaScript 错误**：
   - 打开控制台（F12）查看错误信息
   - 将错误报告给 mod 作者

---

### Q: 游戏选项菜单中找不到作弊扩展设置？

**A**: 定位步骤：

1. **确认入口**：
   - 游戏主界面或游玩中
   - 点击"选项"或"Options"按钮

2. **查找位置**：
   - 在选项菜单中滚动查找
   - 关键词：作弊、Cheat、拓展、Extended
   - 可能显示为独立分类或集成在现有分类中

3. **ModLoader GUI 确认**：
   - 按 `Alt+M`
   - 查看 Mod Config 是否有 `cheat extended` 配置项

4. **版本检查**：
   - 确认安装的是 v1.17+ 版本
   - 旧版本可能有不同的 UI 结构
