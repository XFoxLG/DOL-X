# Cheat Extended 常见问题解答

本文档解答 Cheat Extended v1.17+ 的常见使用问题。

---

## UI 使用相关

### Q: 点击侧边栏的"作弊扩展"按钮没有弹出设置界面？

**A**: 这是 **v1.17+ 版本的正常设计**，不是 bug。

从 v1.17 开始，Cheat Extended 进行了 UI 重构，从集中式面板改为**分散式原生集成**设计。

**v1.17 官方更新说明**：
> 嘗試重新設計側邊欄相關按鈕顯示方式，避免相關UI太過佔空間

**设计理念**：
- **原生集成** - 功能融入游戏原生 UI，而非独立外挂面板
- **情境触发** - 功能在需要的场景自动显示
- **快捷优先** - 高频操作放在侧边栏一键触发

---

### Q: 那我应该在哪里找到作弊扩展的功能？

**A**: Cheat Extended 的功能分布在**三个主要入口**：

#### 1️⃣ 侧边栏（快捷功能）

**功能**：
- ✅ 一键状态恢复 + PC 立即高潮
- ✅ 言靈实时显示（三代言靈系统）
- ✅ 空间节点传送（孤儿院卧室、伊甸家、随身衣柜）

**使用方式**：
- 直接点击侧边栏对应按钮**触发功能**（不是打开设置面板）
- 例如：点击"状态恢复"按钮会立即恢复角色状态

---

#### 2️⃣ 游戏选项菜单（主要设置入口）

**功能**：
- ⚙️ 属性控制面板
- ⚔️ 战斗设置（伤害加倍/疼痛衰减）
- ⏰ 时间控制
- 💰 商业功能配置
- 🥛 大量挤奶模式
- 🐍 大爆精模式
- 🎓 学习内捲模式
- 👗 添加服装功能

**使用方式**：
1. 游戏内点击 **"选项"（Options）** 按钮
2. 在选项菜单中找到 **"作弊拓展"** 相关设置
3. 调整所需功能参数

---

#### 3️⃣ 场景内 Widget（情境功能）

**功能**：
- 🏠 孤儿院卧室 → 随身衣柜（异次元空间衣柜）
- ⚔️ 战斗场景 → 敌人 HP/AP 实时显示
- ✨ 言靈编辑界面（新增/编辑/删除言靈）
- 🎨 魔术迴路功能（自定义纹身）
- 🌍 场景创建功能

**使用方式**：
- 进入对应场景后，功能会**自动显示**在页面相应位置
- 例如：进入孤儿院卧室后，会看到"随身衣柜"选项

---

### Q: 为什么要改成这种设计？旧版不是挺好的吗？

**A**: v1.17 重构的主要原因：

1. **减少 UI 占用空间**
   - 旧版独立面板占用大量屏幕空间
   - 新版分散式设计更简洁

2. **更贴近原生游戏体验**
   - 功能融入游戏原有界面
   - 不像传统"外挂面板"那样突兀

3. **按使用频率优化**
   - 高频操作（状态恢复、言靈）放侧边栏一键触发
   - 低频设置（属性调整）放选项菜单

4. **情境相关性**
   - 战斗功能在战斗时显示
   - 衣柜功能在卧室显示
   - 避免功能堆砌

## 功能使用相关

### Q: 言靈系统怎么用？

**A**: 言靈系统（三代言靈）使用方式：

**查看言靈**：
- 侧边栏会实时显示已添加的言靈列表

**新增言靈**：
1. 方式一：通过魔术迴路功能（文字框输入言靈命令）
2. 方式二：在言靈编辑界面添加

**执行言靈**：
- 点击侧边栏显示的言靈名称即可执行

**编辑/删除言靈**：
- 进入言靈编辑界面进行管理

**特点**：
- 支持同时添加多个言靈
- 调用游戏内原生 widget 和 JS
- 可自定义复杂功能序列

---

### Q: 随身衣柜在哪里？

**A**: 随身衣柜功能位置：

1. **通过空间节点传送**：
   - 侧边栏点击"空间节点"按钮
   - 选择"随身衣柜"传送

2. **在孤儿院卧室访问**：
   - 进入孤儿院卧室
   - 页面会显示"随身衣柜"选项
   - 点击进入异次元空间衣柜

**功能**：
- 存储/切换服装
- 不受场景限制的衣柜访问

---

### Q: 如何修改角色属性/时间？

**A**: 属性和时间控制位置：

1. 游戏内点击 **"选项"（Options）**
2. 找到 **"作弊拓展"** 或相关设置项
3. 在以下功能中调整：
   - **属性控制面板** - 修改角色各项属性
   - **时间控制** - 调整游戏时间
   - **Debug 模式** - 开启调试功能

**注意**：不要在侧边栏找这些功能，侧边栏只有快捷操作。

---

### Q: 战斗中的敌人 HP/AP 显示在哪里？

**A**: 战斗信息自动显示：

1. **触发条件**：进入战斗场景
2. **显示位置**：战斗界面会自动显示敌方 HP（生命值）和 AP（行动点）
3. **无需手动开启**：这是情境触发功能，战斗时自动生效

**相关设置**：
- 伤害加倍
- 疼痛衰减
- 这些功能在"选项"菜单中配置

---

## 版本兼容相关

### Q: 我之前用的是 v1.16，升级到 v1.17 后找不到功能了？

**A**: v1.17 是**重大 UI 重构版本**，功能位置发生变化：

**旧版（v1.16-）**：
- 点击按钮 → 打开作弊面板 → 所有功能集中在面板

**新版（v1.17+）**：
- 侧边栏 → 快捷功能触发
- 选项菜单 → 详细设置
- 场景内 → 自动显示相关功能

**建议**：
1. 重新学习新版 UI 布局（参考本 FAQ）
2. 如实在不习惯，可考虑回退到 v1.16（但会失去新功能）

---

### Q: 为什么我的 DOL-X 使用的是 v1.17 而不是最新的 v1.19？

**A**: 版本选择原因：

**技术限制**：
- Cheat Extended v1.19 需要 maplebirch 框架 ≥v3.2.5
- 但 v3.2.x 版本不存在，实际需要 v4.x
- maplebirchExpansion v1.2.4 不兼容 maplebirch v4.x（API 破坏性变更）

**权衡决策**：
- **选择 v1.17** - 保留 maplebirchExpansion 功能（更长战斗、音乐播放器、理智/灵性属性）
- **放弃 v1.19** - 失去新增功能（农场助手、成就解锁器）

**未来计划**：
- 等待 maplebirchExpansion 发布 v4.x 兼容版本
- 届时可升级到 v1.19 并解锁所有新功能

详见：`AGENTS.md` - "Stable Configuration" 章节

## 故障排查

### Q: 侧边栏的作弊扩展按钮完全不显示？

**A**: 检查项：

1. **Mod 加载验证**：
   - 按 `Alt+M` 打开 ModLoader GUI
   - 确认 `cheat extended` 出现在 Mod 列表
   - 检查状态为 `[Local]` 且无错误标记

2. **版本兼容性**：
   - 确认游戏版本为 v0.5.8.10
   - 确认 maplebirch 框架已加载

3. **控制台检查**：
   - 按 `F12` 打开浏览器控制台
   - 查找 `[Cheat Extended]` 相关错误信息

4. **重新加载**：
   - 刷新页面（F5）
   - 清除浏览器缓存后重试

---

### Q: 点击侧边栏按钮没有任何反应？

**A**: 可能原因：

1. **按钮类型误判**：
   - 确认点击的是"快捷功能"按钮（状态恢复、言靈、传送）
   - 这些按钮会**立即执行功能**而非打开界面

2. **功能条件未满足**：
   - 某些功能可能需要特定条件（如在特定场景）
   - 检查游戏内提示信息

3. **冲突检测**：
   - 检查是否与其他 mod 的 UI 冲突
   - 尝试禁用其他 mod 测试

4. **JavaScript 错误**：
   - 打开控制台（F12）查看错误信息
   - 将错误报告给 mod 作者

---

### Q: 游戏选项菜单中找不到作弊扩展设置？

**A**: 定位步骤：

1. **确认入口**：
   - 游戏主界面或游玩中
   - 点击"选项"或"Options"按钮

2. **查找位置**：
   - 在选项菜单中滚动查找
   - 关键词：作弊、Cheat、拓展、Extended
   - 可能显示为独立分类或集成在现有分类中

3. **ModLoader GUI 确认**：
   - 按 `Alt+M`
   - 查看 Mod Config 是否有 `cheat extended` 配置项

4. **版本检查**：
   - 确认安装的是 v1.17+ 版本
   - 旧版本可能有不同的 UI 结构

### Q: 如何知道某个功能在哪个入口？
