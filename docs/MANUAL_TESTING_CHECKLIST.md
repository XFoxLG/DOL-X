### 言灵系统详细测试流程（2026-06-17更新）

**前置条件**：Cheat Extended已加载，游戏正常运行

#### 1. 启用言灵系统
- [ ] ESC → Options → 作弊扩展标签
- [ ] 向下滚动找到"言灵集"部分
- [ ] 点击"言灵集开关"按钮
- [ ] 确认状态显示为"开"（绿色）
- [ ] 确认"启用侧边栏言灵编辑相关UI"已勾选

#### 2. 创建测试言灵（查询功能）
- [ ] 在"在此输入言灵代码"文本框输入：
  ```
  金钱：<<print $money>>
  ```
- [ ] 在"在此输入言灵名称"输入：`查询金钱`
- [ ] 点击"加入"按钮
- [ ] 确认侧边栏"言灵集"折叠框出现
- [ ] 展开折叠框，确认显示：`(1) 金钱：[当前金钱值]`

#### 3. 创建测试言灵（执行功能）
- [ ] 在代码框输入：
  ```
  <<set $money += 1000>>
  ```
- [ ] 名称输入：`加钱`
- [ ] 点击"加入"按钮
- [ ] 侧边栏确认新增：`(2) <<set $money += 1000>>`

#### 4. 验证自动执行机制
- [ ] 记录当前金钱值（从言灵1查看）
- [ ] 点击任意房间链接（触发页面刷新）
- [ ] 回到侧边栏查看言灵1
- [ ] **确认金钱值增加了1000**（证明言灵2已执行）
- [ ] 再次切换房间，确认再次增加1000

#### 5. 编辑言灵
- [ ] Options → 作弊扩展 → 言灵集
- [ ] 展开"选择言灵"折叠框
- [ ] 下拉框选择"加钱"
- [ ] 点击"查看选中"
- [ ] 在代码框修改为：
  ```
  <<set $money += 5000>>
  ```
- [ ] 点击"编辑选中"
- [ ] 切换房间测试，确认每次增加5000

#### 6. 删除言灵
- [ ] 选择言灵下拉框 → 选择"加钱"
- [ ] 点击"删除选中"
- [ ] 切换房间，确认金钱不再自动增加
- [ ] 侧边栏确认言灵2消失

#### 7. 清除所有言灵
- [ ] 点击"清除所有言灵"按钮
- [ ] 确认侧边栏言灵集为空
- [ ] 确认无代码继续执行

#### 8. 高级测试（可选）

**测试复杂代码**：
- [ ] 创建言灵：
  ```
  <<if $money lt 1000>><<set $money = 10000>><</if>>
  ```
- [ ] 验证条件逻辑正确执行

**测试多条件链接**：
- [ ] 创建言灵：
  ```
  [[回家|Bedroom][<<set $time = 420>>]]
  ```
- [ ] 点击链接，验证传送+时间修改同时生效

**安全测试（验证警告的必要性）**：
- [ ] 创建错误代码：
  ```
  <<set $nonexistent_variable.property = 123>>
  ```
- [ ] 确认游戏报错或变量污染
- [ ] 用"清除所有言灵"恢复

#### 预期结果总结

✅ **正常行为**：
- 言灵存储后，侧边栏实时显示
- 每次页面刷新（切换房间/链接跳转）时自动执行
- 编辑/删除立即生效
- 代码语法错误会显示在控制台

❌ **异常标志**：
- 侧边栏不显示言灵列表
- 代码不执行或执行效果不符预期
- UI操作无响应
- 游戏崩溃或存档损坏

## 快速言灵测试（Quick Yanling）

**测试步骤**：
- [ ] Options → 作弊扩展 → "快速言灵"标签
- [ ] 显示预设功能列表（如"永不耗氧"、"每日自动外状态恢复"）
- [ ] 点击任一预设项旁边的复选框
- [ ] 验证对应效果生效（如水下不掉氧气值）
- [ ] 再次点击相同复选框
- [ ] 验证效果取消

**预期行为**：
- 快速言灵作为一键开关，无需编写代码
- 状态持久化保存到存档
- 可与自定义言灵集并用

**与自定义言灵集的区别**：
- 自定义言灵集：用户编写 SugarCube 代码，存储在 `$cccheat[]`
- 快速言灵：作者预写的常用功能，UI 开关控制
- Custom Spellbook mod：游戏内魔法书系统，与言灵无关
