## 性能优化调研（本会话新查）

- 社区/Wiki 一致方案：DoL 游戏内 **设置 → 关闭天气效果 / 减少动画 / 降低图像质量** 能明显减轻低配设备卡顿。这是**游戏内玩家侧开关**，不改包也能用。
- 重度美化栈（BEES/AU 多图层）在低配设备本就吃性能，减少启用的装饰图层可缓解。
- "改脸切换卡"在"无损最高画质"底线下没有干净的图片侧解法（无损压缩不减解码开销）。唯一构建侧理论杠杆是预加载，成本高收益不定，不推荐。
- 结论：性能优化主要在**游戏内设置**层面（玩家可调），DOL-X 构建侧无安全高收益的改动空间。

## 环境备忘（本会话踩坑）

- PowerShell wrapper 下 `cd /d` 失效、`&` 被当后台任务符、`:(top)`/paren pathspec 报错；用 `cmd /c` + `working_directory` 参数最稳。
- 代理偶发 EOF 断连（gh api），重试即可，非构建失败。
- **git rm 一批文件时，只要有一个文件名拼错，整批报错回滚、实际一个都没删**。本会话因把 GREENFIELD 拼成 GRENFIELD 中招一次；教训：删除/移动后必须 `git status` 核实，不凭回显假设成功。
