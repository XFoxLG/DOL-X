# 已知问题

## custom_hair (自定义染发)

**版本兼容性问题**

该 Mod 仅支持 DoL v0.5.2.7 - v0.5.2.10 范围内的版本。

**影响**
- 在 v0.5.2.10 以上版本中使用可能导致游戏崩溃或功能异常
- 目前 DOL-X 构建基于 v0.5.2.x 系列，暂时可以正常使用
- 未来升级到 v0.5.3.x 或更高版本时需要评估该 Mod 的兼容性

**缓解措施**
- 当前保持基础游戏版本在 v0.5.2.x 系列
- 密切关注上游作者的更新动态
- 如发生兼容性问题，可临时从构建中移除该 Mod

**状态**: 监控中

**参考**
- GitHub Issue: https://github.com/HiddenCirno/DoL-CustomHair/issues/3
- 作者回复确认版本限制

## 通用注意事项

### 基础游戏版本依赖

DOL-X 的所有 Mod 都依赖于特定版本的 Degrees of Lewdity 基础游戏。在升级基础游戏版本时，需要：

1. 验证所有 Mod 的兼容性
2. 更新测试套件
3. 在发布前进行充分测试
4. 在 Release Notes 中明确标注版本要求

### Mod 加载顺序

某些 Mod 对加载顺序敏感，特别是：
- maplebirch 框架应在依赖它的 Mod 之前加载
- UI 相关 Mod 可能存在优先级冲突

当前构建系统通过 `config/build.toml` 中的顺序控制加载，如遇问题需调整顺序。

### 社区支持

由于使用了多个第三方 Mod，部分问题可能需要联系原作者或社区寻求支持。建议：
- 在报告问题前先验证是否为 Mod 冲突导致
- 提供详细的错误日志和复现步骤
- 注明使用的完整 Mod 列表和版本信息
