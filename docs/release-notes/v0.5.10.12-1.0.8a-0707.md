# DOL-X v0.5.10.12-1.0.8a-0707

## 本次更新

DoL 0.5.10.12 早期整合版，采用汉化 1.0.8a、秋枫白桦框架 3.1.14、框架扩展包 1.2.4 与作弊拓展 1.18。

提供基础版、AU-F、AU-M、AU-A，各含 ZIP 与 APK。

下载文件按本版配置重建；更换版本前请导出存档。

## 版本构成

- **游戏本体**：DoL 0.5.10.12 · **汉化**：1.0.8a
- **框架**：[秋枫白桦框架](https://github.com/MaplebirchLeaf/SCML-DOL-maplebirchFramework) v3.1.14

  - [NPC社交栏头像](https://github.com/Eudemonism00/DOL-npcicon-mods/) 1.4

  - [NeoUI](https://github.com/RyaraSUKI/dol-neoui-patch)

## 实测范围

- AU-F 的构建文件与该版本原件完成内容检查；基础版、AU-M、AU-A 仅按同版配置构建，缺少对应原件对照。
- 未完成本版本四种模型的实际游玩验证。

## 已知问题与使用提示

- D.O.L.I 悬浮窗图标、NPC 侧边栏立绘和衣服层可能显示不全，相关修复见 [0713](https://github.com/XFoxLG/DOL-X/releases/tag/v0.5.10.12-1.0.8a-0713)。
- **NPC 动态服装**：开启「PC 模型模式」后，部分具名 NPC 缺少配套服装数据。可关闭该模式，使用「NPC 侧边栏图像显示」。
- **脸部加载提示**：切换脸型时可能出现图片加载失败。该版本未完成所有妆效验证；遇到异常请保留存档与错误信息。
