# 言灵作弊集（Yanling Cheat Collection）v1.0.1 备份副本

这是「言灵作弊集」独立版本 v1.0.1 的备份副本，也是 DOL-X 整合包内置的那一版。
原作者已经删除了这个功能的独立发布仓库（网页和接口都访问不到了），之后把它并入了
自己的另一套整合里。这份备份保留了独立版本在 4.x 框架上可用的最后一版。

## 怎么用、和整合包怎么搭配

- 如果你要玩 DOL-X 整合包：**不需要下载这个文件**，整合包里已经内置了同一份。
- 如果你要自己按 DOL-X 的流程重新构建：原仓库已删除，直接用这里的压缩包，用法与普通 mod 相同。
- 它需要配合秋枫白桦框架 4.1 及以上版本使用。
