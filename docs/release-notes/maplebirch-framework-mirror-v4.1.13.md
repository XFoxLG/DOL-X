# 秋枫白桦框架 v4.1.13 备份副本

这是 DOL-X 在 `-0802` / `-0804` 两次发布里使用的「秋枫白桦框架」（maplebirch）v4.1.13
官方文件的原样备份。**未做任何修改**，与官方发布时的文件逐字节相同。

## 这是什么、为什么会有它

框架作者已经把这个版本从官方发布页删除（2026-10-15 复查确认），而它是 DOL-X 的
`-0802` / `-0804` 两次发布实际使用的版本。为了让这两个旧包的组件在「官方文件消失」之后
仍然能被原样复现，这里保存了一份当时的原件。

框架作者会删除旧版本，也会在同一个下载位置悄悄替换文件；这份备份是防止「官方文件消失
或被替换」的保险。

## 怎么用、和整合包怎么搭配

- 如果你要玩 DOL-X 整合包：**不需要下载这个文件**。当前整合包内置的是更新的框架版本，
  和这个文件不是同一个版本。
- 如果你要复现 `-0802` / `-0804` 旧版整合包，或按早期流程自行构建：在官方源已经拿不到
  这一版时，用这里的压缩包替代即可；它是普通 mod 压缩包，放进 mod 加载列表就能用。
- 它和当前整合包内置的框架**不是**同一个文件，不要用它替换新整合包里的框架。
