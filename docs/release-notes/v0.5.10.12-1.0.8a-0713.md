# DOL-X v0.5.10.12-1.0.8a-0713

## 本次更新

DoL 0.5.10.12 维护版，修正 D.O.L.I 图标及 NPC 侧边栏显示。

提供基础版、AU-F、AU-M、AU-A，各含 ZIP 与 APK。

下载文件按本版配置重建；更换版本前请导出存档。

## 更新内容

- 修正 D.O.L.I 悬浮窗图标无法显示的问题。
- 修正框架 3.1.14 的 NPC 侧边栏立绘和衣服层图片命名。

## 已知问题与使用提示

- **NPC 动态服装**：开启「PC 模型模式」后，部分具名 NPC 缺少配套服装数据。可关闭该模式，使用「NPC 侧边栏图像显示」。
- **脸部加载提示**：切换脸型时可能出现图片加载失败。该版本未完成所有妆效验证；遇到异常请保留存档与错误信息。
