# 秋枫白桦框架 v4.1.7 备份副本（源码重建）

这是「秋枫白桦框架」（maplebirch）v4.1.7 的存档副本。框架作者已经从官方发布页删掉了
这个版本，官方原件也已失效，这里保存的是**用作者公开的源码和官方自动构建流程重建**的版本：
功能与官方当年发布的版本一致，但它不是当年那份文件的逐字节拷贝。

## 这是什么、为什么会有它

框架作者会删除旧版本，也会在同一个下载位置悄悄替换文件。旧整合包和依赖旧框架的 mod 很
容易因此「找不到对应版本」而装不上，所以这里按版本留档，方便需要旧框架的玩家取用。

## 怎么用

- 下载后按你平时装 mod 的方式，把它加进 mod 加载列表即可。
- 装之前先看下面「适用游戏版本」一栏；游戏版本低于下限时框架不会加载。
- 如果你在玩 DOL-X 整合包：**通常不需要它**，整合包已经内置了经过完整验证的框架版本，
  不要用这个旧版本去替换。
