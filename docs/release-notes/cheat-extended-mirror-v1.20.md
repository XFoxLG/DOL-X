# Cheat Extended v1.20 备份副本

这是 DOL-X 整合包内置的「作弊拓展」（Cheat Extended）v1.20 的原样备份副本。

## 这是什么、为什么会有它

作者的上游发布通道是「可变通道」：同一个下载位置被原样替换过多次，同一个链接在不同时间
下载到的文件可能不是同一份。这个备份固定住 DOL-X 使用的那一份（2026-10-02 的版本，
新增发色自定义功能），保证整合包不会因为你什么时候构建而拿到不同的文件。

## 怎么用、和整合包怎么搭配

- 如果你要玩 DOL-X 整合包：**不需要下载这个文件**，整合包里已经内置了同一份。
- 如果你要自己按 DOL-X 的流程重新构建：上游又发生替换或删除时，用这里的压缩包替代即可，
  用法与普通 mod 相同（放进 mod 加载列表）。
- 单独把它放进别的整合包，等于给那个整合包装上作弊功能，请按需自行判断。
