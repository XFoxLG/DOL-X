# DOL-X v0.5.10.12-1.0.8a-0802

## 本次更新

DoL 0.5.10.12 的框架升级版，采用秋枫白桦 4.1.13。

提供基础版、AU-F、AU-M、AU-A，各含 ZIP 与 APK。

下载文件按本版配置重建；更换版本前请导出存档。

## 更新内容

- 框架从 3.1.14 升到 4.1.13，作弊拓展更新到 1.20。
- 框架扩展功能改用独立的更长遭遇战与言灵作弊集。
- AU-F、AU-M、AU-A 首次内置 AU Face 脸部扩展。
- 内置旧图片名称兼容模组。

## 实测范围

- AU-F 检查了框架加载、作弊菜单及部分功能；AU Face 的设置入口与选项可操作。
- 更长遭遇战与言灵作弊集只检查了加载，妆效未完整验证。
- 基础版、AU-M、AU-A 仅完成构建与打包内容检查。

## 已知问题与使用提示

- **NPC 动态服装**：开启「PC 模型模式」后，部分具名 NPC 缺少配套服装数据。可关闭该模式，使用「NPC 侧边栏图像显示」。
- **AU Face 仪态不匹配**：切换脸型后可能出现图片加载失败或桌宠空白，该问题在 [0808](https://github.com/XFoxLG/DOL-X/releases/tag/v0.5.10.12-1.0.8a-0808) 修复。
- **云存档**：需自行配置服务器；本地存档和导出存档可独立使用。
- **食物偏好报错**：更多恋人 0.1.6.0 与本版游戏存在版本差异，相关修复见 [0804](https://github.com/XFoxLG/DOL-X/releases/tag/v0.5.10.12-1.0.8a-0804)。
