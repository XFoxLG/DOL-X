# 秋枫白桦框架 旧版游戏构建合集（DoL 0.5.8.10 / 0.5.9.8）

这是「秋枫白桦框架」（maplebirch）的**旧版游戏专用历史构建合集**。框架作者已经从官方
发布页删掉了这些文件，官方原件也已失效，这里保存的是用作者公开的源码和官方自动构建流程
重建的版本：功能与官方当年发布的版本一致，但它们不是当年那些文件的逐字节拷贝。

## 这是什么、为什么会有它

同一个框架版本当年会针对不同游戏版本分别打包（文件名里的数字就是它要求的最低游戏版本）。
作者删版后这些文件一起消失，玩旧版游戏、或用旧版整合包的玩家就再也找不到能用的框架。
本合集专门收存当年**为游戏 0.5.8.10 / 0.5.9.8 两条旧线**打包的那批文件；为较新游戏版本
打包的文件在各自版本的备份条目里，不在这里。

## 怎么用

- 先看下表的「适用游戏版本」：文件名里的数字**不高于**你的游戏版本就能用
  （例如 0.5.9.8 的游戏既可以用 0.5.8.10 那一批，也可以用 0.5.9.8 那一批）。
- 下载后按你平时装 mod 的方式，把它加进 mod 加载列表即可。
- 如果你在玩 DOL-X 整合包：**通常不需要它**，整合包已经内置了经过完整验证的框架版本，
  不要用这个旧版本去替换。
