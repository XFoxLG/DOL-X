## 已知问题与使用提示

- **AU Face 雀斑、腮红和泪痕**：本版取图兼容调整未观察到视觉改善，相关显示仍待验证。
- **碱性糖改脸眼睛发白**：小人和桌宠可能不显示虹膜，尚未修复，可暂时换用其它脸型。
- **AU 桌宠显示边缘**：右侧出现脸部特写边缘时，将「选项 → 模组设置 → 秋枫白桦框架 → 桌宠遮罩分割线」设为 0px。
- **旧档迁移**：已验证的修复只覆盖脸型与仪态不匹配。更早版本的其它脸部异常尚未确认，遇到问题请保留存档与错误信息。
- **NPC 动态服装**：开启「PC 模型模式」后，部分具名 NPC 缺少配套服装数据。可关闭该模式，使用「NPC 侧边栏图像显示」。
- **云存档**：需自行配置服务器；本地存档和导出存档可独立使用。
