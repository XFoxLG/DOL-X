# 技术档案：v0.5.10.12-1.0.8a-0802

> 玩家向正文：`docs/release-notes/v0.5.10.12-1.0.8a-0802.md`。
> 本文件是技术证据档，只进仓库，不会成为 GitHub Release 正文。

## 目标身份

- 游戏本体：DoL 0.5.10.12 · 汉化 1.0.8a · 构建日期 2026-08-02
- 产物：base / AU-F / AU-M / AU-A ×（ZIP + APK）= 8 件
- 上一版基线：`-0713`，框架 3.1.14 线

## 技术变更

- 框架 3.1.14 → 4.1.13。4.x 是当时唯一在维护的版本线，多数 mod 新版本只认 4.x。
- 旧「秋枫白桦扩展包」退役，功能拆成两个官方独立包：LongerCombat 1.0.1 与 YanlingCheatCollection 1.0.1。
  旧扩展包在新框架上会报错，因此不再收录。
- Cheat Extended v1.18 → v1.20。
- AU 脸部扩展（`【AUsDoL】facial expansion`）首次进入公开发布，只进三个 AU 变体构建。
- 内置 Legacy-Art-Mods-Compat 1.0.3-plusV1.1：把旧式图片名请求（`basehead.png` / `blush1.png`
  这类无连字符写法）映射到社区现行的连字符命名。

## 已知问题与后续更正

- **本版发布说明里「AU 改脸红框 = AU 缺素材图」的归因是错的**，已在后续版本更正。
  0808 复查后的真实根因：换脸后仪态被置成不存在的 `default`，解析链于是去请求一套并不存在的
  眼睛图片；AU 素材本身是齐的。修复见 `0808`。
- More Love v0.1.6.0 与 0.5.10.12 存在版本错配：打开食物偏好页会抛错。`0804` 已升到 v0.1.7.0 修复。
- 云存档功能没有公共服务器，开箱状态下不可用。

## 证据边界

- AU-F 已上机实测：新框架栈加载干净，作弊拓展界面可打开、抽查功能可用。
- LongerCombat / YanlingCheatCollection 只验证到「装上并加载成功」。
- base / AU-M / AU-A 只完成自动构建与产物审计，没有上机。
