## 可复现验收

两个脚本都只依赖已构建的产物与显式传入的输入目录：

```powershell
python tools/candidate_acceptance/browser_acceptance.py --repo . --variant base `
  --artifacts-dir <ZIP 所在目录> --diagnostics-dir <diagnostics 目录> `
  --snapshot <1014-device-saves-copy.json>
```

```powershell
python tools/candidate_acceptance/android_acceptance.py --repo . --variant base `
  --artifacts-dir <APK 所在目录> --diagnostic-dir <诊断 APK 目录> `
  --diagnostics-dir <diagnostics 目录> --snapshot <1014-device-saves-copy.json> `
  --adb <adb.exe> --serial <设备序列号> --package <候选包名>
```

`--variant` 取 `base`、`au-f`、`au-m`、`au-a`。已存在诊断阶段报告时，安卓脚本可加
`--resume-normal` 只重跑正常包恢复与触摸读档。脚本不清除应用数据，也不修改原始快照。
