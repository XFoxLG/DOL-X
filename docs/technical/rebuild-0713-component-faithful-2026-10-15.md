AU-A 因原件不存在，只能陈述为「尺寸一致 + 交叉一致性成立 + 残差有可复现解释」。

## 四、0713 专属的三个坑

1. **老 CLI 的 `warmup` 没有 `--codes` 参数**（后来才加）。
   写 `warmup --codes …` 会直接报参数错误；0713 年代必须
   `warmup --workspace . -v`，也就是预热整个组合矩阵——原 CI 当年也是这么跑的。
2. **本地生成的 `maplebirch-v3-layer-compat` 容器字节**。
   首轮重建 ZIP 四码分别差 base +10 / au-f +4 / au-m +13 / au-a −4 字节，
   逐槽对照后只剩槽 35 不同：内嵌条目内容相同，差在容器属性。实验确认，把该 zip 的两个 DOS
   时间戳改回原件值、`create_system=3`、非 `boot.json` 条目
   `external_attr=0o100644<<16` 后，**与原件槽 35 逐字节相同**。
   该归一化已写入重建驱动（`normalize_local_mod_zip()`）；重跑后
   base / au-f / au-m 三码 ZIP 字节数与原件**精确一致**。
3. **`index.html` 在两种载体里的成员名不同**：APK 内是
   `assets/www/index.html`，ZIP 内是 `Degrees of Lewdity.html`。
   逐条目/逐槽脚本必须按载体取成员名，否则会误判为「文件缺失」。

## 五、AU-A ZIP 的 +3 字节：逐码 Lyra 时间戳

AU-A 的 ZIP 比原件清单大 3 字节（109,905,345 vs 109,905,342）。
这不是「缺件」或「换件」的迹象，而能对上原 CI 的一个已证实行为：

**原 CI 给每个构建码生成的 Lyra 元数据 mod 盖的是该码自己的构建时刻。**
用 0808 的四件原件（AU-F/M/A + base 全部幸存）实测，同一次构建里四码的
Lyra 槽时间戳并不相同：

```text
base  09:38:42      au-f  09:38:42      au-m  09:38:56      au-a  09:39:02
```

我们的 0713 重建把四码**统一冻结**为从幸存 au-f 原件读到的 `13:31:50`。

为了确认这种偏差足以产生「几字节」的量级，做了一个校准实验
（`.local/_lyra_stamp_delta_experiment.py`）：对真实 HTML 里的 Lyra 槽
重新盖时间戳，再用与 `lyra.utils.create_zip` 相同的压缩设置
（ZIP_DEFLATED、默认 level 6、raw deflate）重新压缩整份 HTML，比较文件体积：

| 相对 au-f 时间戳的偏移 | 预测 ZIP 体积 |
|---|---|
| 0 秒（= 我们的重建值） | 109,905,345（与实际文件**精确吻合**，模型校准到 0） |
| −2 秒 / −12 秒 / +5 秒 | **109,905,342**（与原件清单一致） |
| −20 秒 / −30 秒 / +10 秒 | 109,905,340 / 109,905,339 / 109,905,337 |

也就是说：几秒量级的逐码时间戳差异，完全可以造成 3 字节的体积浮动，
而且模型在「我们的取值」处精确复现了实际文件大小。

**证据边界（不得写成已证明的唯一原因）**：AU-A 原件（ZIP 与 APK）都已随
0713 Release 一起消失，所以无法做逐条目对照，也无法反推出当年的确切
时间戳。能陈述的是：残差量与逐码时间戳抖动的机制和量级一致，
且 AU-A 使用的模型载荷与 0802/0804 重建所用的同一份
（sha256 `e93c82e2…`），其上游与已被原件证明逐字节一致的 AU-F 载荷
出自同一个 release。

## 七、边界（必须写进任何对外说明）

- **逐字节一致仅指逐条目内容**：ZIP 条目的存放顺序与时间戳仍与原件不同，
  所以文件级 sha256 不一致。做过实验（见 0804 档案）：把全部条目时间戳
  改成原件值后哈希仍不同，证明顺序差异独立存在。
- **AU-A 没有原件**，只有尺寸级与交叉一致性证据；0713 的 Release 与 tag
  在线上均已不存在。
- **载体结构性差异**：ZIP 比 APK 多 `CREDITS.md` / `LICENSE` / `README.md`，
  APK 多 Cordova 脚手架文件，属载体固有区别，不是构建错误。
- **未发布**：本轮全部产物留在本机 `DOL-X-rebuild-0713\output\`（本机路径，与本仓库同级）
  与两个对照 worktree 内，未上传、未创建/修改任何线上 Release 资产或正文；
  任何上线动作需先经用户审阅。
