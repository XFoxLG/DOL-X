# 2026-11-14 共享兼容修复验证

本次验证沿用现有候选配置、缓存和构建入口。新候选仍为正式中文
`0.5.12.13-chs-1.0.1a`、MapleBirch 5.6.2、原作者作弊拓展 1.20.3.1
及 AU 面部扩展 1.2.16；旧框架仅用于回退。

## 已修复的行为

- Legacy Plus V1.1 根据真实原图或映射目标判断图片是否存在，不再仅凭重命名规则返回存在。
  原图、有效 ModLoader 图像记录与当前 BSA 模型都保留；读取顺序不变。
- MapleBirch 4.1.14 的脸部选图先查询当前模型与构建资源，避免首次请求不存在的候选文件。
  无法找到必需资源时仍保留原错误行为。
- 旧 AU 面部扩展 1.2.8 的面纹关闭状态在框架路径中生效。其面部图层首次注册时同步桌宠，
  合并原图层属性，保留绘制顺序、显示条件和过滤器。该修复仅用于实际 4.1.14 原包，
  不应用到 5.6.2 与面部扩展 1.2.16。
- 原 1014 组合的 CustomHair 同步初始化四种发色，不发送示例域名请求。
- 更多恋人 0.1.7.0 / 0.1.8.0 的可选协作检查使用模组名称表；原版作弊拓展
  1.20 / 1.20.3.1 在可选框架存在时继续取得完整版本对象，缺少该框架时不触发必需依赖查询错误。

第三方原件保持不变，修改只作用于构建副本。适用来源、检查和退出条件登记在
`lyra/compatibility.py`。

## 剩余覆盖

底包的 `style.css`、`usettings.js` 与启动横幅请求仍返回 404，原始日志完整保留。
旧组合本轮共享修复通过，但全请求无错条件仍未通过。新候选的安卓完整复验尚未完成，
原 1.75 GiB MuMu 环境及 AU-A 间歇 Java 桥接问题继续保留未闭环状态。
真实安卓设备、HarmonyOS、个人长期存档与 DOLI 在线服务仍未覆盖。
本次 AU-A 读取使用既有候选测试档，不等同于安卓 1014 快照迁移；
成功复测不覆盖间歇桥接异常和历史低内存退出记录。
本次基础版安卓检查在一次后续启动中遇到原生崩溃：MuMu 增删虚拟输入设备时，
`InputDeviceModifier` 对空 `InputDevice` 调用 `getId()`，WebView 随后 SIGTRAP 退出。
复验取得保存重启一致和正常 APK 触摸读档记录，但最终一轮 UIAutomator 以 135 退出，
完整脚本仍记为失败。正常安装包已恢复，原有 IndexedDB 槽及旧存储核对保留。
CDP 存档调用语法和测试存储恢复问题已在诊断脚本中修正。
四种版本的本次安卓检查均已执行，完整通过数为 0。AU-F 与基础版受到相同的模拟器输入设备
原生崩溃及 UIAutomator 135 退出影响，正常产物重新安装保留。
AU-M 和 AU-A 的游戏功能、旧档、保存重启、正常 APK 触摸读取及原存档保留检查通过，
但各有 9 条 `img/misc/locations/home/[object Object]` 请求失败；已定位为地点初始化跨异步等待后读取被替换的共享对象。修复尚未构建进完整游戏，四种完整安卓验收仍未通过。

候选尚未公开发布，默认版本保持 1014。来源与许可见[资源说明](../DISTRIBUTION_POLICY.md)。
